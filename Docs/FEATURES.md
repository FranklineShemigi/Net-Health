# Net-Health Features

## Current Features

### Authentication

Secure user authentication pages including:

- User Registration
- User Login
- Forgot Password

---

### Dashboard

The central hub of the application where users can access all available tools.

Current dashboard modules include:

- Drug Library
- Dose Calculator

Upcoming modules are displayed as placeholders for future development.

---

### Drug Library

Browse essential medicines with detailed information.

Features:

- Search medicines by name
- Search medicines by category
- Prescription (Rx) indicator
- Over-the-counter (OTC) indicator
- Essential medicine badge
- View detailed drug information

---

### Drug Details

Displays comprehensive information for a selected medicine.

Includes:

- Generic name
- Brand names
- Drug class
- Category
- Dosage forms
- Available strengths
- Adult dosing
- Paediatric dosing
- Prescription status
- Essential medicine status

---

### Dose Calculator

Calculates weight-based paediatric medicine doses.

Current features:

- Medicine selection
- Weight input
- Age input
- Automatic dose calculation
- Recommended frequency
- Maximum daily dose
- Reset calculator
- Safety disclaimer

---

## Planned Features

### Drug Interaction Checker

Compare two medicines and identify:

- Interaction severity
- Clinical explanation
- Recommended action

---

### AI Tutor

Interactive AI learning assistant that explains:

- Medicines
- Diseases
- Pharmacology
- Clinical concepts

---

### Clinical Simulator

Practice realistic patient cases including:

- History taking
- Diagnosis
- Medicine selection
- Clinical decision making

---

### Doctor Verification

Healthcare professionals will be able to verify their credentials before accessing professional features.

---

### Consultation Booking

Patients will be able to schedule consultations with verified healthcare professionals.

---

### User Profiles

Personal dashboards with:

- Saved medicines
- Learning progress
- Recent activity
- Favourite drugs
